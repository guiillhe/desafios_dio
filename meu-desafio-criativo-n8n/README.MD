# 🎯 Desafio Criativo: Planejando Automações com N8N Usando Apenas Bons Prompts
## 📋 Meu prompt final

``` text
Atue como um especialista em N8N.


Quero criar uma automação no N8N para ser notificado todo o começo do dia  quais são meus compromissos.

Público ou responsável:

uso pessoal

Resultado esperado:

saber toda manhã quais são os meus compromissos do dia
Ferramentas envolvidas:

google calendar e whatsapp

Fluxo desejado:

1. olhar o calendario toda a manhã num horario x

2. iterar todos os compromissos do dia 
3 .disparar uma unica mensagem com todos os compromissos


Regras importantes:

1. enviar somente os compromissos do dia em questão
2. enviar apenas de segunda a sexta feira 
3. enviar uma mensagem motivacional na segunda feira para a semana junto com os compromissos 
4. enviar uma mensagem de "sextou" após os compromissos de sexta 


crie um arquivo md com o seguinte conteudo:
Explique quais nós do N8N devem ser utilizados e a lógica de funcionamento do workflow.
```
